Политика конфиденциальности Plant Alarm

Последнее обновление: 25 июля 2026 г.

Plant Alarm — это виджет для Windows и приложение для Android, которые напоминают о поливе растений. У приложения нет серверов, аккаунтов и регистрации — эта страница объясняет, какие данные обрабатываются и как.

Данные о ваших растениях

Название, интервал полива, дата последнего полива, заметки и фото каждого растения хранятся локально: на десктопе — в файле на самом компьютере, на телефоне — в хранилище приложения. Эти данные никуда не отправляются и не видны разработчику — у Plant Alarm просто нет сервера, на который их можно было бы отправить.

Синхронизация между устройствами

Десктоп и мобильное приложение могут синхронизировать список растений напрямую друг с другом по локальной Wi-Fi сети (IP-адрес десктопа вводится в приложении вручную). Синхронизация не проходит через интернет, облако или сторонние серверы — только внутри вашей домашней сети.

Резервное копирование

Функция экспорта/импорта создаёт файл резервной копии только по вашему явному действию и сохраняет его туда, куда вы сами укажете (папка на компьютере или на телефоне). Разработчик не получает копию этого файла.

Уведомления

Напоминания о поливе планируются локально на самом устройстве и не проходят через сторонние push-серверы.

Реклама (Google AdMob)

Мобильное приложение показывает рекламные баннеры через Google Mobile Ads SDK (AdMob). Для показа и измерения эффективности рекламы Google может собирать рекламный идентификатор устройства и другие технические данные в соответствии со своей Политикой конфиденциальности и Политикой в отношении рекламных технологий. Управлять персонализацией рекламы можно в настройках Android: Настройки → Google → Реклама на устройстве. На момент публикации этой версии используются только тестовые рекламные ID Google — реальная реклама будет включена позже, без изменения того, какие данные собирает сама техническая инфраструктура AdMob.

Дети

Plant Alarm не предназначено специально для детей и не собирает данные, зная, что пользователь — ребёнок.

Удаление данных

Поскольку все данные хранятся только локально, удаление приложения (и, на десктопе, папки с его данными) полностью удаляет все данные о ваших растениях.

Изменения политики

Эта страница может обновляться по мере развития приложения — актуальная версия всегда доступна по этому адресу.
