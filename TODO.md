# Идеи для доработки

Каждой задаче/багу присваивается код `PW-NNN` (общий счётчик, без деления на фичи/баги) —
указывается в начале коммит-мессенджа (`PW-005: ...`) и в пункте списка ниже.
Подробности реализации и проверки — в `CHANGELOG.md`, здесь только краткая суть задачи.
Следующий свободный код: **PW-050**.

- [x] `PW-041` Баг: изменение любого поля растения (например, «Полить») на одном устройстве при синхронизации стирало фото, добавленное на другом устройстве — фото теперь мерджится независимо от остальных полей
- [x] `PW-047` Баг: на мобильном экспорт бэкапа писал файл в приватный кэш приложения и открывал только меню «Поделиться» — если пользователь просто закрывал его, файл был недоступен и терялся. Теперь используется Storage Access Framework — как на десктопе, с настоящим диалогом выбора папки
- [x] `PW-048` Баг: авто-синхронизация «при запуске» на мобильном реально срабатывала только при холодном старте процесса (переустановка, принудительное закрытие, перезагрузка телефона) — обычное открытие приложения иконкой/из списка последних просто возвращает уже работающий JS-процесс из фона, не перевыполняя эффект с пустым списком зависимостей. В сочетании с тем, что резервная суточная фоновая задача ОС сама по себе opportunistic (не запрашивает исключение из батарейной оптимизации), реальные попытки синхронизации могли не происходить сутками даже при рабочем и доступном по Wi-Fi десктопе. Добавлен `AppState`-слушатель — попытка синхронизации теперь повторяется при каждом возврате приложения на передний план (суточный throttle внутри `performSync` работает как раньше)

`PW-015`–`PW-019`, `PW-042`–`PW-046` — задачи публикации (сторы, аккаунты, подписи, продвижение), вынесены во внутренний чек-лист вне репозитория.

На агрессивных Android-прошивках (MIUI, Samsung, EMUI и т.п.) задача может неделями не выполняться, если приложение просто лежит в фоне. Найдено при разборе `PW-048` — там резервным путём стал `AppState`-listener на возврат в foreground, но чистый фоновый (без открытия приложения) сценарий синхронизации всё ещё ненадёжен
