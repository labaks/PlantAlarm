# Идеи для доработки

## Версия 1.0.1 (план)
- [x] Временная синхронизация телефон↔десктоп по локальной сети (двустороннее слияние по `updatedAt`, тем­стоуны для удалений, IP десктопа вводится вручную в настройках телефона, фоновая попытка ~раз в сутки) — реализовано и проверено вживую на реальном телефоне и десктопе в одной Wi-Fi сети, включая удаление растения и повторную синхронизацию (не воскресает)
- [x] Поле «дней с последнего полива» при добавлении растения — иначе новое растение всегда считалось политым сегодня
- [x] Дата последнего полива в редактировании растения (сейчас поле «Дней с последнего полива» показывалось только при добавлении) — реализовано на десктопе (`AddPlantWindow` + `PlantItem.SetLastWatered`) и мобильном (`PlantFormModal` + `initialLastWatered`), проверено вживую на обеих платформах: изменение значения с 0 на 3 у «Ктенанты» (интервал 5 дн.) корректно пересчитало срок полива с «Через 5 дн.» на «Через 2 дн.»
- [ ] Звук уведомления вкл/выкл
- [ ] Фото цветка в карточке (иконка вместо/рядом с названием)
- [ ] Заметки к растению («у окна», «не любит перелив», сорт удобрения)
- [x] Локализация интерфейса (русский + английский), английский по умолчанию — десктоп: `Services/Strings.cs`, выбор языка через выпадающий список (ComboBox) в Settings, переключается вживую без перезапуска; мобильное: `src/i18n.tsx`, свой компонент `Select` (выпадающий список, т.к. в RN нет нативного `<select>`) в модалке синхронизации, persist через AsyncStorage; лендинг (`docs/index.html` + `docs/en/index.html`, с заметным `<select>` для языка и отдельными скриншотами на английском) и README (`README.md` + `README.en.md`) тоже переведены — проверено вживую на десктопе и на реальном телефоне (пересборка APK, установка, переключение языка туда-обратно)
- [ ] Перетаскивание пунктов в списке (ручная сортировка)
- [ ] Десктоп: сборка/релиз через GitHub Releases (прикреплять .exe/инсталлятор к релизу в репозитории)
- [ ] Мобильное: публикация в Google Play (нужен аккаунт разработчика $25, политика конфиденциальности, прохождение модерации/content rating)
- [ ] Политика конфиденциальности (обязательна для Google Play из-за рекламы)
- [ ] Реклама на мобильном: баннер через Google AdMob (`react-native-google-mobile-ads`, Expo config plugin, нужен prebuild — не работает в Expo Go). Начать с официальных тестовых ID Google, заменить на реальный рекламный юнит, когда подтвердится/восстановится аккаунт AdMob

- [x] Баг: иконка-капля полива на мобильном — обводка (stroke) выходила за границы `viewBox` и обрезалась с краёв — исправлено в `DropletIcon.tsx` (добавлен отступ), проверено на реальном телефоне скриншотом: обводка больше не обрезается

- [x] Кнопка «Полить» всегда активна; при нажатии не по расписанию показывается диалог «до полива осталось N дн., полить сейчас? Отмена/Полить» — реализовано на десктопе (`ConfirmWindow` с настраиваемым текстом кнопки) и мобильном (переиспользован `ConfirmModal` с `confirmLabel`), проверено вживую на обеих платформах, включая нажатие «Полить» и обновление статуса
