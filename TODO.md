# Идеи для доработки

## Про сам полив
- [ ] Фото цветка в карточке (иконка вместо/рядом с названием)
- [ ] Заметки к растению («у окна», «не любит перелив», сорт удобрения)
- [ ] История поливов (последние N раз)
- [ ] Напоминание по дням недели, а не только «раз в N дней»

## Про уведомления
- [ ] Настраиваемое время проверки/показа уведомлений (например, только с 9:00 до 21:00)
- [ ] Звук уведомления вкл/выкл
- [ ] Кнопка «Полил» прямо в тосте Windows (Action Center), без открытия виджета

## Про виджет
- [ ] Тема оформления (светлая/тёмная/акцентный цвет)
- [ ] Сортировка списка (по срочности / по имени / вручную)
- [ ] Сворачивание уже политых/не срочных растений в списке
- [ ] Экспорт/импорт списка растений (на случай переустановки Windows)

## Инфраструктурное
- [ ] Автообновление (проверка новой версии)
- [x] Портирование на Android (`mobile/`, см. `mobile/BUILD.md`) — без синхронизации с десктопом, данные независимые
- [ ] Публичная синхронизация между устройствами через облачный бэкенд (Supabase/Firebase: аккаунты пользователей, realtime, разрешение конфликтов по `updatedAt`) — понадобится при публикации приложения
- [x] Временная синхронизация телефон↔десктоп по локальной сети (двустороннее слияние по `updatedAt`, тем­стоуны для удалений, IP десктопа вводится вручную в настройках телефона, фоновая попытка ~раз в сутки) — реализовано и проверено вживую на реальном телефоне и десктопе в одной Wi-Fi сети, включая удаление растения и повторную синхронизацию (не воскресает)
