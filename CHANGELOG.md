# Патч-ноуты

Рабочий журнал изменений для будущих релизных заметок. Пишем сюда по мере разработки, публикуем при выходе версии.

## Неопубликованное

- В окне настроек десктопа появилась ссылка-баннер на GitHub-репозиторий проекта (иконка + текст, открывает страницу в браузере).

## 1.0.1 — 2026-08-07

- Портирование виджета на Android (мобильное приложение) — данные пока независимые от десктопа, без синхронизации.
- Временная синхронизация телефон↔десктоп по локальной сети (двустороннее слияние по дате изменения, работает только в одной Wi-Fi сети, IP десктопа вводится вручную на телефоне).
- При добавлении растения появилось поле «Дней с последнего полива» — раньше новое растение всегда считалось политым сегодня.
- Капля полива теперь показывает «сколько воды осталось», а не «сколько прошло времени»: сразу после полива капля полная, а к сроку следующего полива постепенно пустеет (раньше было наоборот — полная капля означала «пора поливать»). Десктоп и мобильное.
- Кнопка «Полить» больше не блокируется до наступления срока — теперь она всегда активна. При поливе раньше графика показывается диалог-подтверждение: «До полива осталось N дн. Полить сейчас?». Десктоп и мобильное.
- В редактировании растения появилось поле «Дней с последнего полива» (раньше было доступно только при добавлении нового растения) — можно скорректировать дату полива задним числом. Десктоп и мобильное.
- Исправлена обрезанная по краям обводка иконки-капли на мобильном (обводка выходила за границы viewBox).
- Добавлена локализация интерфейса: русский и английский (по умолчанию — английский), переключается в настройках выпадающим списком без перезапуска приложения. Десктоп и мобильное. Лендинг и README теперь тоже на двух языках, с заметным переключателем языка и отдельными скриншотами для английской версии.
- Мобильное: экран настроек отделён от синхронизации — на экране «Settings» теперь только язык и пункт «Sync with desktop», который открывает синхронизацию отдельным экраном (не загромождая настройки полями IP/порта/статуса).
- Звук уведомления можно включить/выключить в настройках. Десктоп и мобильное.
- В карточке растения появилось фото (вместо/рядом с названием). Десктоп и мобильное; фото пока хранилось только на самом устройстве, без синхронизации.
- Автоматическая синхронизация с десктопом теперь пытается сработать сразу при запуске мобильного приложения, а не только раз в сутки в фоне.
- Фото растений теперь синхронизируются между десктопом и телефоном (раньше синхронизировались только текстовые данные).
- Исправлен баг на десктопе: иконка-плейсхолдер (росток) оставалась поверх загруженного фото растения в списке.
- Резервное копирование списка растений (с фото): экспорт в файл и импорт обратно, на десктопе и на мобильном (Настройки → «Резервная копия»).
- У растения появилось необязательное поле «Заметки» (например, «у окна», «не любит перелив», сорт удобрения) — заполняется при добавлении/редактировании, синхронизируется между десктопом и телефоном как обычное текстовое поле. На десктопе показывается всплывающей подсказкой при наведении на растение в списке.
- Растения в списке теперь можно переставлять вручную перетаскиванием: на десктопе — за саму строку, на мобильном — за ручку «⠿» справа. Порядок сохраняется и синхронизируется между десктопом и телефоном.
- Исправлен баг синхронизации фото: если на одном устройстве меняли не связанное с фото поле (например, нажимали «Полить»), при следующей синхронизации фото, добавленное на другом устройстве, могло быть ошибочно принято за удалённое и стёрто на обоих устройствах. Теперь фото отслеживается отдельным временем изменения и мерджится независимо от остальных полей растения.
- Мобильное: реклама (баннер AdMob внизу главного экрана, пока с тестовым ID — реальный юнит появится после подтверждения аккаунта AdMob).
- Исправлен баг на мобильном: экспорт резервной копии писал файл в приватный кэш приложения и открывал системное меню «Поделиться» — если его просто закрыть, файл оставался недоступен пользователю и складывалось впечатление, что бэкап потерялся, хотя сообщение сообщало об успехе. Теперь используется настоящий диалог выбора папки (Storage Access Framework), как на десктопе.
- Исправлен баг на мобильном: попытка авто-синхронизации «при запуске» на деле выполнялась только при холодном старте процесса — обычное открытие приложения (иконкой/из списка последних) просто возвращает уже запущенный процесс из фона, и синхронизация могла не пытаться выполняться сутками, даже если десктоп был доступен по Wi-Fi. Теперь синхронизация также пытается запускаться при каждом возврате приложения на передний план.
