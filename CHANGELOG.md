# Патч-ноуты

Рабочий журнал изменений для будущих релизных заметок. Пишем сюда по мере разработки, публикуем при выходе версии.

## Неопубликованное

- Капля полива теперь показывает «сколько воды осталось», а не «сколько прошло времени»: сразу после полива капля полная, а к сроку следующего полива постепенно пустеет (раньше было наоборот — полная капля означала «пора поливать»). Десктоп и мобильное.
- Кнопка «Полить» больше не блокируется до наступления срока — теперь она всегда активна. При поливе раньше графика показывается диалог-подтверждение: «До полива осталось N дн. Полить сейчас?». Десктоп и мобильное.
- В редактировании растения появилось поле «Дней с последнего полива» (раньше было доступно только при добавлении нового растения) — можно скорректировать дату полива задним числом. Десктоп и мобильное.
- Исправлена обрезанная по краям обводка иконки-капли на мобильном (обводка выходила за границы viewBox).
